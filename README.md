تمرین 1:

برای مرتب کردن فایل ها بر اساس حجمشون از دستور زیر استفاده میکنیم:

ls -lS

از بزرگترین به کوچکترین

برای کوچکترین به بزرگترین:

ls -lsr

تمرین 2:

/bin:
شامل برنامه ها و دستورات ضروری سیستم هستش که کاربران عادی هم میتونن ازش بهره ببرن.

/sbin:
دستورات ضروری مدیریتی و سیستمی رو داره که بیشتر برای مدیر سیستم کارایی داره.
